# Security Policy

## Supported Versions

Security fixes are currently provided for the latest version
available on the main branch.

## Reporting a Vulnerability

This repository supports GitHub Private Vulnerability Reporting.

Please use the private vulnerability reporting feature on the
repository's Security tab to report security vulnerabilities.

Do not disclose vulnerabilities publicly before they have
been reviewed and addressed.

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any relevant logs or proof of concept

## Response

Reports will be reviewed as soon as reasonably possible.
The reporter may be contacted for additional information.

Please do not include sensitive personal information in reports.
